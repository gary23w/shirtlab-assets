# Contributing

Start with a focused issue or pull request describing the user-visible change.

## New assets

Supply the original publisher URL, exact source files and SHA-256 hashes, licence text, creator credit, redistribution permission and any per-asset licence overrides. Keep source filenames, palette, geometry and native resolution. Do not admit blank placeholders or formats that the interface cannot faithfully preview and download. Preserve historical embedded notices alongside current publisher declarations; do not silently replace them.

Assets retain their original licences. Brand and game logos may also carry trademark or usage rules. A licence for this repository's code does not change those rules.

## Code

Keep queries, result pages, downloads and memory bounded. Keep search keyboard accessible, filters labelled, and result changes announced. Collections must stay portable and preserve attribution notes. Do not add account keys, commerce code, private logs or personal information to this repository.

Verify changed search, download and collection behaviours using the included tests. Check the mobile layout and a source SVG and PNG download before proposing release.
